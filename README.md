# 🔗 chain-lab

Blockchain learning lab by [Turtleand](https://turtleand.com). Practical, experience-driven content about blockchain technology, DeFi, and the AI x crypto convergence.

**Live at:** [decentralized.turtleand.com](https://decentralized.turtleand.com)

## What This Is

Not a crypto news site. Not a trading guide. This is a builder's perspective on blockchain — learning by doing, documenting what works and what doesn't.

**Topics covered:**
- Chain fundamentals (explorers, tokenomics, L2 landscape)
- Ethereum ecosystem (privacy, account abstraction, Optimism/Base)
- DeFi in practice (stablecoins, DEX routing, risk frameworks)
- AI x Blockchain (agent wallets, payments, private inference)
- Multi-chain (Solana, Bitcoin L2s)

## Quick Start

```bash
# Prerequisites: Node.js 18+
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321)

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server at localhost:4321 |
| `npm run build` | Build for production to `dist/` |
| `npm run preview` | Preview production build locally |
